# Chaos Infrastructure Faults (s16)

## Purpose
Produce complete, safe, runnable infrastructure-level chaos experiments that test system resilience against node failures, resource exhaustion, disk pressure, and cloud provider outages.

## Fault 2: Node Drain

```yaml
apiVersion: litmuschaos.io/v1alpha1
kind: ChaosExperiment
metadata:
  name: node-drain
  namespace: litmus
  labels:
    managed-by: hcprm
    fault-category: infrastructure
    fault-type: node-failure
spec:
  definition:
    scope: Cluster
    env:
      - name: TOTAL_CHAOS_DURATION
        value: "300"            # 5 minutes of drain
      - name: TARGET_NODE
        value: ""               # Target specific node or random
      - name: DRAIN_TIMEOUT
        value: "240"            # Max wait for pods to evict
      - name: NODE_LABEL
        value: ""               # Filter by label
      - name: FORCE
        value: "false"          # Force drain even with PDB violations
```

**Pre-drain safety checks:**
```bash
#!/bin/bash
# pre-drain-check.sh
TARGET_NODE="${1:?Usage: $0 <node-name>}"

echo "=== Pre-Drain Safety Check for $TARGET_NODE ==="

# 1. Verify cluster has >= 3 healthy nodes
HEALTHY_NODES=$(kubectl get nodes --no-headers | grep -c Ready)
if [ "$HEALTHY_NODES" -lt 3 ]; then
  echo "❌ ABORT: Only $HEALTHY_NODES healthy nodes (need ≥ 3)"
  exit 1
fi

# 2. Verify no single-replica stateful pods on target node
SINGLE_REPLICAS=$(kubectl get pods --all-namespaces --field-selector spec.nodeName=$TARGET_NODE \
  -o json | jq -r '.items[] | select(.metadata.ownerReferences[].kind=="StatefulSet") | "\(.metadata.namespace)/\(.metadata.name)"')

if [ -n "$SINGLE_REPLICAS" ]; then
  echo "⚠️  Stateful pods on target node:"
  echo "$SINGLE_REPLICAS"
  echo "Verify these have >1 replicas before draining."
fi

# 3. Verify PodDisruptionBudgets won't block drain
kubectl get pdb --all-namespaces | awk '$4 > 0 {print "⚠️  " $1 "/" $2 " allows " $4 " disruptions"}'

echo "✅ Pre-drain checks passed"
```

## Recovery Procedures

### Node CPU Hog Recovery
```bash
# CPU hog is self-recovering — process terminates at end of chaos duration
# Verify node CPU returns to baseline:
kubectl top nodes | grep <NODE_NAME>
# Expected: CPU% returns to pre-chaos levels within 60s
```

### Node Drain Recovery
```bash
# Uncordon the node:
kubectl uncordon <NODE_NAME>

# Verify pods reschedule:
kubectl get pods --all-namespaces --field-selector spec.nodeName=<NODE_NAME> -w

# Verify node is Ready:
kubectl get node <NODE_NAME>
```

### Disk Fill Recovery
```bash
# Chaos runner cleans up the filled data automatically
# Verify disk usage returns to normal:
kubectl exec -it <POD_NAME> -- df -h <CONTAINER_PATH>

# If manual cleanup needed:
kubectl exec -it <POD_NAME> -- rm -rf /var/lib/data/diskfill/*
```
